# KCI 후속 연구 설계 가이드

## 제안하는 논문 범위

**제안 제목: 「Physical AI 개념 학습을 위한 시계열 기반 에너지 운영 시뮬레이션 교육 플랫폼 개발 및 적용」**

이 프로그램은 물리 법칙의 단순 모형에서 상태를 관측하고, 예측과 제약에 따라 행동하며, 결과를 다음 판단에 반영하는 교육 환경입니다. 실제 건물·배터리를 제어하지 않습니다. 따라서 논문의 주장은 시뮬레이션 플랫폼의 작동과 교육 적용 범위로 한정합니다.

## 선행 원고와의 연결

사용자가 제공한 원고 **「Auditable Daily Energy Forecasting From Long-Term Campus Meter Reports: Register-Consistency Screening and Chronological Offline Evaluation」**를 데이터 출처와 예측 평가 원칙의 기반으로 삼습니다. 제공 파일의 존재가 출판·게재 확정을 뜻하지는 않습니다.

원고는 2019년 6월~2023년 6월의 보고서 아카이브와 15개 건물급 계량 채널의 일별 예측을 다룹니다. 계량 채널은 독립된 건물 동수와 다를 수 있습니다. 수신 시각과 시간대별 부하를 입증하는 자료가 없으므로 이를 이용해 실시간 서비스나 통신 지연 효과를 소급 주장하지 않습니다. 원고의 약 28% 개선은 기준 대비 예측오차 감소이며 에너지 절감률이 아닙니다.

후속 연구는 기존 예측표를 재제시하는 데 그치지 않고, 교육 목표·상태 전이 모형·단계별 피드백 화면·개인 수행평가를 새 기여로 제시합니다. 기존 방법과 자료를 재사용한 범위를 명시하고 관련 원고의 상태에 맞게 인용합니다.

## 연구 질문

1. 개발한 실습은 학습자의 예측–판단–실행–피드백 관계 이해와 제약 해석 능력에 어떤 변화를 보이는가?
2. 학습자는 처음 보는 수요·발전 변화에서 정보를 근거로 정책을 해석하고 수정할 수 있는가?
3. 관측값 정체 상황을 예측 오류나 정상 상태 변화와 구별할 수 있는가?

운영 성능 자체가 주제라면 연구 질문을 별도로 정합니다. 교육 효과와 제어 알고리즘 우수성을 한 번의 작은 실험에서 모두 입증하려 하지 않습니다.

## 플랫폼 검증 실험

| 검증 대상 | 필요한 증거 |
|---|---|
| 에너지 수지 | 각 구간의 공급·소비·충방전 수지 잔차 |
| ESS 상태 전이 | 효율을 반영한 저장량 증감, SOC·출력 제한 |
| 예측 정보 시점 | 미래 입력 변경이 과거 예측·결정에 영향을 주지 않는 확인 |
| 정책 비교 | 공통 평가 기간, 동일 초기 상태·설정·외란 |
| 오류 시나리오 | 실제 상태와 관측 상태의 분리, 요청·적용 명령 기록 |
| 반복 가능성 | 전체 입력 자료와 SHA-256, 합성 자료 생성 시드, 모델·정책 이름, 설정, 프로그램 버전 |

시뮬레이션 결과는 모형의 가정에 조건부입니다. 현재 모형은 배터리 열화·온도·상세 전압·건물 열관성·사람의 쾌적성을 검증하지 않습니다. 규칙 기반 정책의 결과를 전역 최적해, MPC, 강화학습 또는 LLM 추론 결과로 표기하지 않습니다.

### 정책 비교 시 주의

기본 비교는 ESS 없음, 현재값 대응, 하루 전 계획, 피드백 재계획입니다. 예측기의 효과를 비교할 때는 정책을 고정하고, 피드백 효과를 비교할 때는 예측기를 고정합니다. 자료·효율·용량·초기 SOC·시나리오 강도는 공통으로 유지합니다.

하루 전 계획 정책은 매일 시작 시점의 관측 SOC를 이용하여 하루 계획을 다시 생성하고 그날 안에서는 유지합니다. 완전히 관측을 배제한 개루프와 동일하지 않습니다. 현재값 대응에는 구간 내 집계 측정값을 즉시 사용할 수 있다는 가정이 있으며, 예측 정책에는 이전 구간까지 확인된 정보만 사용합니다. 비교표에 이 정보 조건을 명시하고 현장 지연의 실측 결과로 해석하지 않습니다. 관측 정체 실험에서도 물리적 SOC·출력 제한은 적용됩니다.

관측 정체는 SOC 채널에만 적용합니다. 부하·태양광은 별도 계측 채널로 계속 관측되므로 순부하와 확인된 예측 잔차는 갱신됩니다. 전체 실험 JSON의 `input_records`는 예열 기간을 포함하며 `input_sha256`으로 입력 일치를 확인할 수 있습니다. 합성 자료의 생성 시드와 달리 업로드 자료에는 추가 무작위성이 없으므로, 같은 입력·설정·프로그램 버전으로 비교합니다.

구매전력, 수출전력, PV 자가소비율, 최종 SOC, 등가 순환량, 제약에 의한 명령 제한을 함께 제시합니다. **최종 저장 에너지가 다른 실험에서 구매전력 감소만으로 순수 절감 효과를 주장하지 않습니다.** 동일 종단 SOC 조건의 추가 실험이나 잔량 보정을 사용하려면 방법을 명확히 정의해야 합니다. 지표 하나의 개선과 다른 지표의 악화를 함께 논의합니다.

시간별 최대 구매전력은 한 시간 평균의 최대값이며 순간 피크나 검증된 요금용 수요전력이 아닙니다. 일별 모드의 최대값은 일평균 구매전력 수준이므로 시간대별 피크 저감 주장에 사용하지 않습니다. 일별 모드에서는 구간 내 발전·소비의 겹침을 알 수 없어 PV 자가소비율을 계산하지 않습니다. 비용을 연구하려면 검증된 요금제와 계약 조건을 별도로 구현해야 합니다.

## 교육 적용 설계

주 결과변수를 사전에 하나 또는 소수로 지정합니다. 예를 들어 **개인 전이 과제 루브릭 점수**를 주 결과로 두고, 개념 검사·완료 시간·교수자 도움·만족도를 보조 결과로 둡니다. 새 오류 상황에 대한 수행을 포함하여 단순 화면 익숙함과 구분합니다.

가능한 설계는 동일한 학습 목표·수업 시간의 기존 예측 실습과 폐루프 실습 비교입니다. 집단 배정, 선행 능력, 교수자, 평가 문항 난이도를 통제하거나 기록합니다. 표본 수는 예상 효과와 분석 방법을 근거로 계획합니다. 임의의 인원수를 게재 조건처럼 제시하지 않습니다.

비교집단 없이 소규모로 적용한다면 제목과 결론을 **개발 및 적용 사례**에 맞춥니다. 사전·사후 변화만으로 플랫폼의 인과 효과를 단정하지 않습니다. 만족도나 자기효능감은 실제 수행 향상을 대체하지 않습니다.

두 평가자의 독립 채점을 통해 평가 일치도를 확인하고, 개인과 팀의 평가 단위를 구분합니다. 초 단위 로그 수천 행을 독립 실험 수천 회로 취급하지 않습니다. 같은 학생의 반복 측정과 같은 날짜의 시계열 의존성을 분석에서 고려합니다. 차이의 크기와 불확실성을 제시하고, 유의확률만으로 효과를 설명하지 않습니다.

## 원시 자료 적용 전 확인표

- [ ] 부하와 발전이 같은 현장·기간·시간 기준인가?
- [ ] 부하가 총소비량인지 태양광 차감 후 수전량인지 확인했는가?
- [ ] kW, 구간 kWh, 누적 kWh를 구분했는가?
- [ ] 상위·하위 계량의 중복을 제거했는가?
- [ ] 결측·리셋·제외 기준과 원본 추적 정보를 보존했는가?
- [ ] 모델 선택과 평가 구간을 시간 순서로 분리했는가?
- [ ] 합성 자료와 실제 자료, 다른 기간의 시나리오 결합을 구분했는가?
- [ ] 실제 TSFM 추론을 하지 않은 결과에 TSFM 명칭을 붙이지 않았는가?

## 논문 구성과 필요한 표

1. 서론: 기존 시계열 수업에서 예측과 행동의 연결이 어려운 문제, 연구 질문
2. 관련 연구: 시계열 교육, 에너지 운영 가상실습, Physical AI 교육의 선행연구 검토
3. 설계: 학습 목표, 에너지 수지, 정책, 정보 시점, 인터페이스
4. 콘텐츠: 주차별 활동, 오류 시나리오, 개인 수행 과제와 루브릭
5. 검증 및 적용: 자동 검증, 비교 조건, 참여자·절차·분석 방법
6. 결과 및 논의: 운영 지표와 학습 성과를 구분하고 한계 분석
7. 결론: 확인한 범위의 성과, 실제 하드웨어 연계의 후속 과제

핵심 표는 입력 자료 출처, 정책별 정보·행동, 플랫폼 검증 결과, 학습 목표–과제–평가 연결, 개인 수행 결과입니다. 결과표의 빈칸을 가정한 성공 수치로 채우지 마십시오. 현재 저장소에는 학생 실험 결과나 현장 절감 실적이 포함되어 있지 않습니다.
