# 6주 교육 운영안

대상은 Python 기초를 배운 학습자이며, 주 3시간을 가정한 조정 가능한 수업안입니다. ESP32 없이 각자 PC에서 실행합니다. 운영 목표는 예측 정확도 순위 맞히기가 아니라, **미래의 불확실성과 현재의 관측을 구분하고 제약을 만족하는 행동을 설계하는 것**입니다.

## 학습 목표

수업 후 학습자는 다음을 수행합니다.

1. 구간 에너지 kWh와 전력 kW, 계량값과 누적값을 구분한다.
2. 미래 자료를 사용하지 않는 예측과 시간 순서에 따른 평가를 설명한다.
3. 예측, 운영 정책, 환경의 제약 적용, 관측 피드백을 구분한다.
4. 명령한 출력과 실제 적용된 출력이 달라진 이유를 설명한다.
5. 처음 보는 부하·발전 변화와 관측 오류에서 정책을 진단한다.

## 주차별 계획

| 주차 | 실습 | 개인 산출물 |
|---|---|---|
| 1 | 합성·실측 자료 구분, CSV 시간축·단위·계량 경계 점검 | 자료 설명서와 오류 사례 분석 |
| 2 | 전주 기준과 과거 같은 요일 평균 비교, 예측오차 해석 | 어느 기간·시점에 틀리는지 설명 |
| 3 | ESS 수지식, SOC·출력·효율, 정책별 목적 확인 | 한 단계 상태 갱신 수계산 |
| 4 | 관측–판단–명령–상태 변화의 단계별 재생, 네 정책 비교 | 같은 설정의 정책 비교 보고서 |
| 5 | 부하 급증·발전 감소·SOC 관측값 정체 | 명령·관측 로그를 근거로 오류 진단 |
| 6 | 공개하지 않았던 조건에서 재실험과 개선안 제시 | 개인 전이 과제·성찰 기록 |

## 실습 과제

### 과제 1: 좋은 예측이 항상 좋은 운영인가?

동일한 자료와 ESS 조건에서 두 예측 방식을 비교합니다. 예측오차와 구매전력·최종 SOC를 기록합니다. 오차가 줄어도 운영 결과가 비슷하거나 나빠질 수 있는 조건을 설명합니다. 예측기와 정책을 동시에 바꾸지 않습니다.

### 과제 2: 피드백의 역할

부하 급증 또는 발전 감소 시나리오에서 하루 전 계획과 피드백 재계획을 비교합니다. 사용한 정보의 시점, 제안 출력, 적용 출력, 저장 상태가 달라지는 지점을 찾습니다. 피드백이 항상 개선한다고 가정하지 말고 차이가 없는 구간도 기록합니다.

### 과제 3: 관측이 멈췄을 때

SOC 관측값 정체 조건을 실행합니다. 실제 SOC와 관측 SOC가 어떻게 달라지는지 찾고, 물리 한계가 제어 요청을 제한하는 시점을 설명합니다. 독립된 부하·태양광 계측은 계속 정상 갱신된다는 조건을 구분합니다. “예측 모델을 바꾸면 해결되는가?”, “관측 시각과 신선도 확인이 필요한가?”를 각각 논증합니다.

### 과제 4: 일별 자료의 해석 한계

같은 일일 소비량을 만드는 서로 다른 시간별 부하 패턴을 생각해 봅니다. 일일 수지가 같아도 왜 시간별 구매전력이나 ESS의 운전 가능성이 다를 수 있는지 설명합니다. 일별 결과에서 주장할 수 있는 것과 없는 것을 구분합니다.

## 개인 수행평가 루브릭

다섯 영역을 각각 0~4점으로 평가합니다. 기준 예시의 점수는 실제 학생 결과가 아닙니다.

| 영역 | 0점 | 2점 | 4점 |
|---|---|---|---|
| 데이터 해석 | 단위·출처를 설명하지 못함 | 단위와 기본 시간축 설명 | 계량 경계·누락·시나리오 결합 한계까지 설명 |
| 예측 해석 | 실측과 예측을 혼동 | 오차 계산·방향 설명 | 시간 누설과 예측–운영 차이를 근거로 설명 |
| 제약 이해 | SOC·출력 한계를 무시 | 기본 한계를 적용 | 효율·최종 잔량·적용 출력까지 일관되게 해석 |
| 피드백 이해 | 명령과 결과를 혼동 | 상태 변화를 다음 판단과 연결 | 정보 시점을 구분하고 재계획의 장단점 설명 |
| 오류 진단 | 원인 추정 근거 없음 | 한 로그를 근거로 진단 | 복수 증거와 대안 원인을 비교하고 검증 방법 제시 |

1점과 3점의 세부 기준은 수업 전 평가자 협의로 정합니다. 일부 또는 전체 답안을 두 평가자가 독립 채점하고 평가자 간 일치도를 확인합니다. 팀 보고서와 별도로 개인 설명·수계산·새 시나리오 문제를 채점합니다.

## 수업 기록 양식

- 학습자 익명 ID, 실습 일시, 프로그램 버전
- 입력 자료 출처와 시간 해상도
- 예측 방식, 정책, ESS 설정, 외란 종류와 강도
- 실행 전 가설과 그 근거
- 실행 결과, 최종 SOC, 예측오차, 제약에 의해 달라진 명령
- 관찰한 오류, 진단 근거, 수정 제안
- 도움 횟수, 완료 시간, 아직 설명하지 못한 내용

실제 학생 자료를 연구에 사용할 경우 기관의 연구윤리·동의·심의 기준을 확인하고, 성적 평가와 연구 참여를 구분합니다. 공개 결과에는 개인을 식별할 수 있는 정보를 넣지 않습니다.
